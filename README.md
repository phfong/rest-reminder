# 健康休息提醒（Rest Reminder）

基于 Python Tkinter 的 Windows 桌面久坐提醒工具。定时提醒起身活动，帮助养成健康的工作节奏。

## 功能特性

- **定时提醒**：可自定义工作时长（默认 45 分钟），时间到后弹出提醒并进入休息倒计时（默认 5 分钟）
- **锁屏检测**：通过 Windows API（`OpenInputDesktop`）检测真正的锁屏/解锁动作，解锁回来后自动重置工作时间
- **任务栏图标倒计时**：用 PIL 动态生成带剩余分钟数的任务栏图标，工作阶段显示绿色、休息阶段显示橙色，无需打开窗口即可查看剩余时间
- **单实例保护**：通过命名互斥量（Mutex）防止重复启动；再次启动时会激活已运行实例的窗口
- **设置持久化**：工作/休息时长保存到 `rest_reminder_config.json`，重启后自动加载
- **一键跳过/重置**：支持"立刻休息""跳过休息""重置计时"操作

## 环境要求

- Windows 系统
- Python 3.x
- [Pillow](https://pillow.readthedocs.io/)（用于生成任务栏图标）

```bash
pip install pillow
```

## 使用方法

双击 `rest_reminder.pyw` 直接运行，或双击 `启动提醒.bat` 后台启动（无控制台窗口）。

程序主界面：

- 顶部显示当前阶段（"工作中..." / "该活动了！"）与倒计时
- 中部进度条直观显示时间进度
- 可随时修改工作/休息分钟数并点击"应用"，设置会自动保存

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `rest_reminder.pyw` | 主程序 |
| `rest_reminder_config.json` | 配置文件（工作/休息时长） |
| `启动提醒.bat` | 后台启动脚本 |

## 技术要点

- 任务栏按钮图标在 Win10/11 下存在缓存问题，程序通过"更新窗口类图标 + 隐藏/不激活重显窗口"的方式强制资源管理器重建任务栏按钮，实现图标实时刷新
- 倒计时在后台线程执行，UI 更新统一通过 `after()` 调度到主线程，避免跨线程操作 tkinter
